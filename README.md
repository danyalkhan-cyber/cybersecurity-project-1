This project demonstrates practical network reconnaissance using Nmap, a widely used open-source tool for network discovery and security auditing. The objective is to identify active hosts, open ports, and running services within a target network in order to understand its structure and potential attack surface.

During this project, various scanning techniques were used including host discovery (ping sweep), TCP SYN scanning, and service/version detection. The results were analyzed to understand how systems expose services over a network and how attackers could potentially identify vulnerabilities through exposed ports and services.

This exercise helped strengthen my understanding of network fundamentals, TCP/IP communication, and basic ethical hacking methodologies used in penetration testing and security assessments.

Key Learning Outcomes:

Network host discovery using Nmap
Port scanning and service detection
Understanding open ports and exposed services
Basics of reconnaissance in ethical hacking
Interpreting scan results for security analysis

Tools Used:

Nmap
Linux (Kali Linux environment)
Command-line interface (CLI)
